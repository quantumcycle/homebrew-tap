# Quantumcycle Homebrew Tap

Homebrew tap for [quantumcycle](https://github.com/quantumcycle) tools.

## Usage

```
brew install quantumcycle/tap/spex
```

## Available tools

| Tool | Description |
|------|-------------|
| [spex](https://github.com/quantumcycle/spex) | A generic parallel process runner with a live terminal UI |
